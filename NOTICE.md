# Release and sanitization notice

This repository package is a sanitized publication artifact derived from a private OSINT evidence workspace.

## Sanitization choices

The public release keeps account handles, aggregate counts, exact Git-object SHAs, protocol outcomes, and source provenance needed to understand the published findings.

It omits raw commit-author email addresses, raw API response pages, private workflow artifacts, and full outbound-follow membership lists.

Identity-morphology findings are therefore released as pair relationships and test outcomes rather than the underlying email strings.

## Attribution boundary

The published evidence supports a shared technical orchestration / generation system across the measured six-account cohort.

It does not establish one human operator, common credentials, shared network infrastructure, a specific vendor, deliberate targeting, publication causation, or malicious intent beyond the measured behavior.

## Failed evidence remains failed

Two accounts did not satisfy the outbound-follow snapshot validation rules. Their retries were bounded in advance, failed closed, and remain excluded from the authoritative overlap measurement.

No six-account outbound snapshot or six-way target intersection is claimed.

The provenance phase found exact cross-owner Git blob reuse but no cross-owner tree SHA reuse and no exact cross-owner author `(name, email)` identity bridge.

The identity phase produced a negative username-to-email association test (`p = 0.5333`) and no cross-owner raw structural-skeleton match.

These negative results are part of the evidence record, not exceptions to be edited away.

## Collection closure

The released investigation is closed. The public package is for review and reproduction of the published result, not an invitation to keep collecting until a stronger claim appears.
